8. GOTCHAS / HARD-WON LESSONS
----------------------------------------------------------------
- COLLECTING SESSION is PER COMPUTER, never per account. Storage is
  localStorage; Pulse's repo constant is `pulse_collecting` and the UI
  uses `collect-mode` radios in the settings view. An account-level flag
  would follow the login to every machine, so one viewer switching off
  would silence the machine that actually collects. Default is ON.
- OFF never claims an extension IS installed - it only stops requiring
  one. A viewer still shows a small 'Viewing only' indicator.
- Staleness is NOT hidden on a viewer. A stale capture or no collection
  in 48h is real account state: it still shows, reworded to point at the
  collecting computer.
- Before building anything extension-status related, grep the repo for
  `_collecting` and 'viewing only' - it is probably already there.
