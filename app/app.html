Install or update

Latest: v1.17.0
⬇ Download the latest extension
  1. Unzip the download to a folder you'll keep (not the Downloads folder).
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and select the unzipped folder.
  4. Come back here and hit Re-run checks.
Already loaded from a local folder?
Replace the files in that folder with the new ones, then click the reload ↻ button on the extension's card in chrome://extensions — no re-install needed.
After any update: reload the extension in chrome://extensions, then reload this page. Chrome keeps the old copy of the collector alive until you do.

If something looks wrong

“Not detected” but it is installed — reload this page; Chrome only injects the collector into tabs opened after the extension loaded.
“Can't start a sync from here” — you're on an extension older than v1.17.0. Download above, reload the extension, reload this page.
“No access token” — reload this page while signed in; the collector is handed its token automatically. If it still says missing, check Your access token above — if that reads Not set, EXTENSION_TOKEN is missing in Cloudflare.
Sync starts then stalls — make sure you're signed in to LinkedIn in this browser, and don't close the LinkedIn tabs the collector opens.
